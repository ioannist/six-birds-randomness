\section{Lean Formalization of the KL Bridge}\label{app:lean}

The companion repository contains a small Lean~4 development, built on mathlib, that machine-checks the Kullback--Leibler identities behind \Cref{prop:cd-kl} \citep{demoura2015leantheoremprover,mathlib2020leanmathematicallibrary}. It is deliberately narrow. It certifies the bridge between KL divergence and the expected log-likelihood ratio, and the zero criterion for a weighted sum of divergences. It does not formalize conditional mutual information or the rest of the paper.

\paragraph{A subtlety about real-valued KL.} In mathlib, the KL divergence $\mathrm{klDiv}(\mu,\nu)$ takes values in the extended nonnegative reals, so it can be $+\infty$. Converting it to a real number with \texttt{toReal} sends $+\infty$ to $0$, and the Bochner integral of a non-integrable function is also defined to be $0$. An identity of the form
\[
\mathrm{klDiv}(\mu,\nu)^{\mathrm{toReal}}=\int \mathrm{llr}_{\mu,\nu}\,d\mu
\qquad(\mu\ll\nu)
\]
is therefore true but can read $0=0$ when the divergence is in fact infinite. For example, on the positive integers, take $\mu(n)\propto n^{-2}$ and $\nu(n)\propto e^{-n}$. Then $\mu\ll\nu$, but the expected log ratio diverges like $\sum_n 1/n$. A faithful real-valued reading needs integrability of the log-likelihood ratio, or a finite space, where integrability is automatic.

\paragraph{What is proved.} The development exports ten theorems. Their transitive axioms, printed by an audit target that is part of the default build, are only Lean's standard \texttt{propext}, \texttt{Classical.choice}, and \texttt{Quot.sound}. There are no \texttt{sorry} placeholders and no project-specific axioms. In mathematical terms, for probability measures $\mu,\nu$ the development proves the following.
\begin{enumerate}
\item \emph{General space.} If $\mu\ll\nu$, then the real-valued identity above holds and the integral is nonnegative, with the caveat just described. If in addition the log-likelihood ratio is $\mu$-integrable, then $\mathrm{klDiv}(\mu,\nu)$ equals the integral as an extended real, so it is finite. Under these hypotheses, the integral is zero if and only if $\mu=\nu$. Without any hypotheses, $\mathrm{klDiv}(\mu,\nu)=0$ if and only if $\mu=\nu$.
\item \emph{Finite space.} On a finite discrete space, the log-likelihood ratio is always integrable. If $\mu\ll\nu$, the divergence equals the finite sum $\sum_x \mu(\{x\})\,\mathrm{llr}_{\mu,\nu}(x)$, with no hidden infinity.
\item \emph{Weighted zero criterion.} If the extended-valued divergence is finite, its real-valued projection is zero if and only if $\mu=\nu$. For nonnegative weights $w_i$ and pairs $(\mu_i,\nu_i)$ whose extended-valued divergences are finite whenever $w_i>0$, the sum $\sum_i w_i\,\mathrm{klDiv}(\mu_i,\nu_i)^{\mathrm{toReal}}$ is zero if and only if $\mu_i=\nu_i$ for every $i$ with $w_i>0$. On a finite space, absolute continuity $\mu_i\ll\nu_i$ for each positive-weight $i$ suffices, and finiteness is derived.
\end{enumerate}
The last item is the abstract form of \Cref{prop:cd-zero}(ii). Take the index $i$ to be a microstate $x$, the weight to be $\pi(x)$, $\mu_i=p_x^{(\tau)}$, and $\nu_i=\bar p_{\Pi(x)}^{(\tau)}$. The absolute continuity it requires is exactly what the proof of \Cref{prop:cd-kl} establishes for occupied microstates.

\paragraph{What is not formalized.} The weights and measures in the weighted theorems are inputs. The development does not construct the stationary package forecasts, and it does not prove the mixture argument that supplies absolute continuity. Nor does it formalize conditional mutual information, the decomposition \eqref{eq:cd-decomposition}, Pinsker's inequality, the memory bound, or budgeted prediction. Those steps rest on the finite proofs given in the main text.
